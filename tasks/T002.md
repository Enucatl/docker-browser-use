# T002 — Compose stack skeleton: networks, Traefik, Authelia, hardening

## Goal

Create a production-shaped `docker-compose.yml` that plugs into the existing homelab Traefik + Authelia edge and applies `compose-security-baseline` hardening, without implementing agent logic yet.

## Context

Sibling stacks under `/opt/docker` share:

- Hardening: `extends.file: ../compose-security-baseline/hardening.yml`
- Ingress network: external `traefik_proxy`
- Authelia forward-auth middleware: `authelia@docker`
- LAN/HTTPS chain: `secured@file`
- Shared domain: `DOCKER_DOMAIN` from `/opt/docker/.env` (typically `docker.home.arpa`)
- Hostname pattern: `{service}.${DOCKER_DOMAIN}`

Canonical simple reference: `/opt/docker/send-bills/docker-compose.yml`.

**Note:** The plan referred to `../baseline-compose-security`; the real sibling directory is `../compose-security-baseline`.

## Dependencies

- T001 (so an app image/build context can be referenced, even as a stub Dockerfile)

## In scope

1. Add `docker-compose.yml` with at least:
   - `controller` (or `api`) — future FastAPI/UI backend; **only** public service on `traefik_proxy` for now
   - Placeholder internal network (`internal: true`) for DB/browser later
   - External network `traefik_proxy`
2. Traefik labels on the public service, matching send-bills:

```yaml
labels:
  - "traefik.enable=true"
  - "traefik.docker.network=traefik_proxy"
  - "traefik.http.routers.browser-use.rule=Host(`browser-use.${DOCKER_DOMAIN}`)"
  - "traefik.http.routers.browser-use.entrypoints=https"
  - "traefik.http.routers.browser-use.tls=true"
  - "traefik.http.routers.browser-use.middlewares=authelia@docker,secured@file"
  - "traefik.http.services.browser-use.loadbalancer.server.port=<app-port>"
```

3. `extends` every service from `../compose-security-baseline/hardening.yml` with an appropriate size profile (`hardened-medium` for API; browser worker comes in T004).
4. Add `.env.example` documenting `DOCKER_DOMAIN` / `COMPOSE_ENV_FILES=../.env` pattern, `TZ=Europe/Zurich`, and app host vars.
5. Add stub `Dockerfile` that can run a placeholder HTTP server or `uvicorn` later (enough for compose build).
6. Document that Authelia wildcard `*.docker.home.arpa` already allows `group:admins` — **do not** edit `/opt/docker/authelia` unless a custom rule is explicitly required.
7. Ensure CDP, Postgres, and future Chrome ports are **not** published on Traefik and not bound to the host publicly.

## Out of scope

- Real Postgres (T003)
- Chromium container (T004)
- Application routes beyond a health endpoint
- Changing Traefik global config

## Acceptance criteria

- [ ] `docker compose config` validates
- [ ] Public service uses `authelia@docker,secured@file` and `entrypoints=https`
- [ ] Only ingress-facing service joins `traefik_proxy`
- [ ] Hardening `extends` present on defined services
- [ ] `.env.example` and secrets directory convention documented (empty `secrets/.gitkeep` or README note; real secrets gitignored)
- [ ] No host-published CDP/VNC ports

## Suggested files

```text
docker-compose.yml
Dockerfile
.env.example
secrets/.gitkeep   # or document in README; keep secrets gitignored
```

## Implementation notes for the model

- Copy patterns from send-bills; do not invent new middleware names.
- Prefer `ports: []` on Traefik-fronted services.
- Mount CA bundle read-only if the app will call internal HTTPS later.
- `extra_hosts` for `${DOCKER_DOMAIN}:host-gateway` is common and acceptable.
