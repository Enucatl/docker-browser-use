# T005 — Docker CI via compose-security-baseline reusable workflow

## Goal

Wire GitHub Actions so images build, scan, and optionally publish using the shared homelab Docker CI workflow.

## Context

Baseline docs: `/opt/docker/compose-security-baseline/README.md`

Reusable workflow: `Enucatl/docker-compose-security-baseline/.github/workflows/docker-ci.yml@main`

Reference wrapper: `/opt/docker/send-bills/.github/workflows/deploy.yml` (or equivalent Docker CI wrapper).

## Dependencies

- T002 (Dockerfile exists)

## In scope

1. Add `.github/workflows/docker-ci.yml` (name must be stable if Trivy remediation is added later).
2. Call the reusable workflow with an appropriate `image_name` (e.g. `ghcr.io/enucatl/browser-use`).
3. If multiple images (controller vs browser), either matrix/build-args or separate workflow inputs — keep it simple; document the choice.
4. Optionally add Trivy remediation wrapper mirroring baseline docs (optional; only if low cost).
5. Ensure workflow does not require committing secrets.

- Changing the baseline repository
