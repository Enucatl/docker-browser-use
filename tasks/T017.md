# T017 — Model-call and browser-action tracing tables/writers

## Goal

Ensure every model call and every browser action is recorded with forensic detail suitable for “why did it click this?” months later.

## Context

**Model calls:** provider, model/version, full redacted prompt/request, raw output, parsed output, latency, tokens, retries, HTTP/request ids, cost estimate. For Jev: candidates, probabilities, selected action/target, alternatives.

**Browser actions:** URL, title, tab, element index, attributes, accessible name, role, bounds if available, Browser Use ids, latency, result, page-changed flag, before/after state artifact refs.

## Dependencies

- T009, T015

## In scope

1. Complete schema fields if T006 left placeholders; migrate as needed.
2. Writer helpers used by the loop and Jev/text clients.
3. Link rows to `agent_events.seq` / event ids.
4. Tests verifying required fields persist.

## Out of scope

- Cost dashboard UI (T029)
- Offline eval harness (T032)

## Acceptance criteria

- [ ] A completed fake run produces queryable `model_calls` and `browser_actions` rows
- [ ] Large inputs optionally reference artifact ids instead of inline megabytes
- [ ] Redaction applied before persistence
