# T018 — Compressed browser-state checkpoints on meaningful changes

## Goal

Store full model-visible browser state as compressed artifacts on meaningful transitions, while keeping `agent_events` rows small and queryable.

## Context

Complete candidate DOM lists, a11y info, bounds, page dimensions, Jev I/O, action schema, retry context — these are archival payloads (MessagePack or JSON + Zstd) referenced by events.

Policy: checkpoint on meaningful page changes, errors, approvals, and periodic intervals — not necessarily every micro-action.

## Dependencies

- T007, T015

## In scope

1. Define “meaningful change” heuristic (URL change, title change, major DOM hash change, error, approval boundary).
2. Serialize observation → compress → artifact store → event with artifact id.
3. Dedup naturally via T007 hashes.
4. Tests for “no checkpoint when nothing changed” and “checkpoint on URL change”.

## Out of scope

- State diffs (T033)
- Screenshot capture (T019)

## Acceptance criteria

- [x] Events remain small; large state only in artifacts
- [x] Replay-relevant observation can be loaded by artifact id
- [x] Checkpoint policy documented and configurable
