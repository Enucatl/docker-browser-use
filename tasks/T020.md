# T020 — Pause, resume, cancel, and retry controls

## Goal

Make runs controllable: pause between steps, resume, cancel cooperatively, and retry failed steps under policy.

## Context

Controller owns lifecycle. UI and API both need these controls. The agent loop must check control flags between steps.

## Dependencies

- T010, T015

## In scope

1. API endpoints: pause, resume, cancel (and optional retry).
2. Persist status transitions with audit events.
3. Worker respects pause (park awaiting resume), cancel (exit cleanly), retry (re-observe + decide).
4. WebSocket notifications for status changes (if T011 present).
5. Tests for pause/resume/cancel race with a slow fake step.

## Out of scope

- Approval-specific waiting (T021) — share the same waiting infrastructure if natural
- Takeover/VNC (T023)

## Acceptance criteria

- [x] Paused run executes no further browser actions until resume
- [x] Cancelled run stops and ends in `cancelled`
- [x] All transitions audited

## Suggested files

```text
src/<package>/agent/controls.py
src/<package>/api/routes/run_controls.py
tests/test_run_controls.py
```

## Implementation notes for the model

- Use an asyncio.Event / DB flag carefully; document the chosen synchronization model.
