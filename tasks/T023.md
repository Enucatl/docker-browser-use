# T023 — Take-control / human-in-the-loop VNC handoff

## Goal

Add “Take control” so a human can interact with the agent Chrome for MFA, CAPTCHA, Bitwarden unlock, passkeys, or weird widgets, then return control to the agent.

## Context

While human controls the session, the agent loop must pause browser actions. After release, the loop resumes with a fresh observe.

## Dependencies

- T022, T020

## In scope

1. API/UI signal: take control / release control.
2. Run status `awaiting_human` (or equivalent).
3. Mutex: agent actions refused while human owns control.
4. Audit events for takeover start/end and operator identity.
5. Optional: disable Jev execution automatically on takeover.
6. Tests for mutex with fake browser executor.

## Out of scope

- Solving CAPTCHAs automatically
- Passkey cryptography

## Acceptance criteria

- [ ] Agent cannot click/type while takeover is active
- [ ] Release resumes loop safely
- [ ] Takeover is Authelia-authenticated

## Suggested files

```text
src/<package>/agent/takeover.py
src/<package>/api/routes/takeover.py
tests/test_takeover.py
```
