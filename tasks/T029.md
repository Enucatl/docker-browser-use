# T029 — Cost entries and simple cost dashboard API/UI

## Goal

Record per-call and per-run costs and expose a simple dashboard for operators.

## Context

`cost_entries` table exists from T006/T017. Aggregate by run, day, model.

## Dependencies

- T017, T024

## In scope

1. Cost estimation helpers (token * price table in config).
2. API: run cost, recent summary.
3. UI panel on run detail + simple history totals.
4. Tests for aggregation math.

## Out of scope

- Billing integrations
- Complex BI

## Acceptance criteria

- [ ] Model calls create cost entries
- [ ] UI shows non-zero cost on a fake priced run
- [ ] Prices configurable without code changes

## Suggested files

```text
src/<package>/audit/costs.py
config/model_prices.yaml
tests/test_costs.py
```
