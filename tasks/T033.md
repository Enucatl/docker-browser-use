# T033 — Artifact retention policy and optional state diffs

## Goal

Add retention/compaction so exhaustive audit remains affordable: keep forever the small logical events; manage large checkpoints/screenshots with policy; optionally store diffs between states.

## Dependencies

- T018, T019

## In scope

1. Configurable retention: e.g. keep all events; downsample screenshots older than N days; keep full checkpoints at boundaries.
2. Optional diff format between consecutive DOM/state checkpoints with periodic full baselines.
3. Job/CLI to apply retention safely (never delete hash-chained events).
4. Tests for policy decisions on fake inventories.

## Out of scope

- MinIO lifecycle rules (T034)
- Changing hash chain history

## Acceptance criteria

- [ ] Retention job cannot delete `agent_events` rows
- [ ] Artifact deletion updates/removes metadata carefully (document orphan handling)
- [ ] Diff feature behind a flag defaulting off until proven

## Suggested files

```text
src/<package>/artifacts/retention.py
src/<package>/artifacts/state_diff.py
tests/test_retention.py
```

## Implementation notes for the model

- Prefer soft-delete markers before hard delete in the first version.
