# T034 — Optional MinIO backend for artifact storage

## Goal

Provide an S3-compatible artifact backend via MinIO while keeping the filesystem backend as default.

## Dependencies

- T007

## In scope

1. Abstract store interface if not already clean.
2. MinIO/S3 implementation (bucket, prefix, SSE if easy).
3. Compose profile `minio` optional service on **internal** network only.
4. Migration notes from filesystem to MinIO (best-effort script optional).
5. Tests with mocked S3 or testcontainers if practical; otherwise interface tests + manual notes.

## Out of scope

- Public bucket exposure via Traefik
- Replacing Postgres

## Acceptance criteria

- [ ] `ARTIFACT_STORE=fs|s3` config switch
- [ ] Default remains filesystem
- [ ] MinIO not on `traefik_proxy` unless explicitly Authelia-gated for admin UI (prefer internal-only)

## Suggested files

```text
src/<package>/artifacts/s3_store.py
docker-compose.yml  # profile minio
tests/test_s3_store.py
```

## Implementation notes for the model

- Credentials via Docker secrets.
- Reuse SHA-256 content addressing as object keys.
